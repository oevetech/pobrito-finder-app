# Pobrito Finder (APK)

App Android que liga o celular ao robo **Pobrito**: bateria no Monitor de baterias, procurar o celular (Wi-Fi e Bluetooth), Estou chegando e mais.

Sem um Pobrito na rede de casa o app nao faz nada. Cada robo baixa daqui a versao mais nova e entrega aos celulares dele.

So os APKs ficam aqui (Releases). O codigo e privado.
